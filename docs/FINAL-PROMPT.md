3) kit API: kit.bg(theme), kit.slam(words, t)(단어마다 0.12초 간격으로 박힘), kit.full(text, t, "dark"|"lime"), kit.card, kit.chip(label, text),

   모든 텍스트는 kit가 자동 줄바꿈(한 줄 15자 안팎, 최대 3줄, 한국어 단어 단위)을 하고 최소 크기를 보장한다.

   흐름: 에토스(chip) → 파토스(chat/slam) → 로고스(numbered/다이어그램) → 결론(full).
   예시 draw() 하나를 이 규칙대로 다시 써서 프롬프트에 넣어.
5) 프로그램 검사(verify 전에 Worker에서): 최소 글자 34px 이상, 텍스트가 안전 여백 안에 있는지, 콘텐츠 면적 25% 이상,
   0.5초 간격 프레임 비교로 4초 넘는 정지가 없는지, 폰트가 G마켓 산스로 렌더됐는지(측정 폭 비교). 실패 사유는 fix-code에 넘겨.
