# UI/UX 명세 — "YouTube Studio에 원래 있던 기능처럼" (FINAL-PROMPT P0-3를 대체)

## 0. 원칙
- 새 디자인 언어를 만들지 않는다. YouTube Studio의 "동영상 업로드" 대화상자 문법을 그대로 쓴다.
- 평평한 다크(#282828 계열) 모달, 1px 테두리, Roboto/Noto Sans KR 14px, 파란 주 버튼(#3ea6ff 배경, 검은 글자), 텍스트 버튼은 흰색·회색.
- 그라데이션, 글로우, ✨, 알약 배지, 영어 대문자 라벨, 개발 용어는 기본 화면에서 금지한다. 기술 증거는 [AI 작업 기록] 접힘 패널에만 둔다.
- 사용자는 "올리기 → 기다리기 → 확인·고치기 → 저장" 네 가지만 한다.

## 1. 진입점 (3곳, 모두 같은 모달을 연다)
- 상단 [만들기] 메뉴: 동영상 업로드 / **AI로 편집해서 업로드** / 실시간 스트리밍 시작
- 왼쪽 내비 "콘텐츠" 아래 "AI 편집" (아이콘 + 한 줄 라벨, 작은 회색 "신규")
- 대시보드 첫 카드: "촬영만 하면 편집은 AI가" + 한 줄 설명 + 파란 텍스트 버튼 [AI로 편집하기]

## 2. 모달 구조 (Studio 업로드 창과 동일한 틀, 데스크톱 960×720 안팎)
```
┌ 제목: "AI로 편집하기"                                         [ⓘ] [✕] ┐
│ 스텝퍼: (1) 업로드 ── (2) AI 편집 ── (3) 검토 ── (4) 내보내기             │
├──────────────────────────────────────────────┬────────────────────┤
│  왼쪽: 단계별 본문                             │ 오른쪽: 미리보기 카드  │
│                                              │ [영상 플레이어]       │
│                                              │ 원본 ⇄ 완성본 토글     │
│                                              │ 길이 0:12 → 0:21     │
├──────────────────────────────────────────────┴────────────────────┤
│ 왼쪽 하단: 상태 문구 "처리 중… 약 40초 남음"            [뒤로] [다음] │
└────────────────────────────────────────────────────────────────┘
```

### (1) 업로드
- 가운데 원형 업로드 아이콘, "동영상 파일을 드래그 앤 드롭하여 업로드", 보조 문구 "10~20초 세로·가로 영상, 말하는 장면이면 더 좋아요".
- 파란 [파일 선택] 버튼. 아래에 작은 텍스트 버튼 [샘플 영상으로 체험하기] (누르면 상단에 "샘플 데이터" 띠 표시).
- 파일을 고르면: 썸네일, 길이, 해상도 확인 → 옵션 2개만:
  · AI 목소리: [여성 차분] [남성 차분] [끄기]
  · 자막: [켜기] [끄기]
- [다음] = AI 편집 시작.

### (2) AI 편집 (진행 화면, 사용자는 기다리기만)
- 왼쪽: Studio의 "검사" 단계처럼 체크리스트가 위에서부터 차례로 완료됨.
  1. 말을 글로 옮기는 중 → "말 37단어를 받아 적었어요"
  2. 잘라낼 곳 찾는 중 → "말이 끊긴 곳 2군데를 찾았어요"
  3. 빠진 설명 찾는 중 → "'왜 특별한지' 설명이 빠졌어요"
  4. 설명 장면 만드는 중 → 장면 썸네일이 하나씩 나타남
  5. 목소리 입히는 중 → "설명 2개에 목소리를 넣었어요"
  6. 완성 화면 다시 확인하는 중 → "글자 크기·잘림을 확인했어요 ✓"
- 실패한 항목은 회색 경고 아이콘과 쉬운 문장("목소리를 만들지 못해 자막으로 대신했어요"). 성공처럼 꾸미지 않는다.
- 하단 진행 막대와 남은 시간. 완료되면 [다음] 활성화.
- 오른쪽 미리보기는 원본 재생.

### (3) 검토 (확인·고치기)
- 오른쪽: 완성본 미리보기(원본 ⇄ 완성본 토글). 아래 장면 띠(원본 회색 블록 / AI 장면 흰 블록, 클릭하면 그 위치로 이동).
- 왼쪽 탭 4개 (Studio 세부정보 탭 스타일):
  · **자막**: 받아 적은 문장 목록(시간 + 텍스트). 텍스트를 바로 고칠 수 있고, 고치면 자막에 반영.
  · **잘린 부분**: "0:03~0:05 '아 다시' (말 실수)" 목록 + [되살리기] 토글. 확신 낮은 컷은 "추천" 표시로만, 기본은 꺼짐.
  · **AI 장면**: 장면 카드(썸네일, 한 줄 대본, [▶ 목소리 듣기], 빠른 수정 [더 쉽게] [더 짧게] [다시 만들기], 그 아래 자유 입력).
  · **AI 작업 기록**(접힘): 실제 응답 모델, 호출별 시간·결과, 코드 출처(Argon 작성/기본 템플릿), 시도 횟수, 검증 결과. 심사용 증거라서 숨기지만 지우지 않는다.
- 수정하면 해당 장면만 다시 만들고 미리보기를 갱신.

### (4) 내보내기
- "완성 영상을 만드는 중… 이 탭을 닫거나 다른 탭으로 옮기지 마세요" + 진행 막대(실시간 녹화라 영상 길이만큼 걸림).
- 완료: 썸네일, 길이, 파일 형식, 파란 [다운로드] 버튼, 텍스트 버튼 [YouTube 업로드용 제목·설명 복사](Argon이 제안, 시간 남으면).

## 3. 반응형
- 1024px 이하: 모달 전체 화면, 미리보기 카드는 위로.
- 600px 이하: 한 열, 스텝퍼는 "2/4 AI 편집" 텍스트로 축약, 내비는 서랍 메뉴. scrollWidth <= innerWidth.

## 4. 음성 인식(받아쓰기)과 컷 경계
- 별도 STT 서비스를 붙이지 않는다. Argon이 영상을 직접 듣고 plan.transcript(구절 단위 start/end/text)를 만든다. 이것이 "말을 글로 옮기는 중" 단계다.
  plan 프롬프트에 "구절은 1~3초 단위, 시간은 0.1초 단위, 실제로 한 말만 그대로 적고 고치지 말 것"을 명시한다.
- 컷 경계 보정(브라우저): 업로드 영상의 오디오를 decodeAudioData로 읽어 20ms 단위 RMS를 계산하고,
  Argon이 정한 컷 시작·끝을 ±0.3초 안의 가장 조용한 지점으로 스냅한 뒤 앞뒤 0.08초씩 여유를 둔다.
  무음 구간(-40dBFS 이하 0.6초 이상)은 Argon 결과와 비교해 "무음" 컷 후보로 추가한다.
- 자막 시간은 transcript를 쓰고, 컷이 적용된 출력 시간으로 다시 계산한다(원본 → 출력 시간 대응표).
- 사용자가 [자막] 탭에서 고친 텍스트가 최종 자막이다.
