## ⏱️ 타임라인별 화면·클릭·대사 (총 3분 / 180초)

### 1. [0:00 ~ 0:20] 문제 제기 & YouTube Studio 대시보드 진입 (20초)
- **화면:** 배포된 Cloud Run URL 접속 → 실제 YouTube Studio 다크 테마를 그대로 재현한 채널 대시보드. 상단 프로모 카드(`✨ 촬영만 하세요. 나머지는 AI가.`)와 좌측 내비게이션의 `✨ AI 제작 (NEW)` 메뉴 클로즈업.
- **행동:** 프로모 카드의 **`[AI 제작 시작]`** 버튼 클릭 → `✨ AI 제작` 스튜디오 뷰로 즉시 전환.
- **대사:**
  > "유튜버가 15초짜리 짧은 설명 영상을 올리려 해도, 박수 치고 다시 말한 NG 컷을 자르고, 말로만 설명해서 시청자가 이해하기 어려운 부분에 모션그래픽 도식을 넣으려면 2시간이 걸립니다. **YouTube AI Studio**는 익숙한 유튜브 스튜디오 안에 **Gemini 4 Argon** 감독을 심어, 원본 촬영본 하나로 컷 편집과 모션그래픽 코드 생성·검증까지 끝냅니다."

### 2. [0:20 ~ 0:50] 원본 영상 업로드 & 멀티모달 기획 (`/api/plan`) (30초)
- **화면:** 상단 4단계 스텝 바(**1. 업로드 → 2. AI 제작 → 3. 확인 → 4. 다운로드**).
- **행동:** **`[새 영상 업로드]`** 클릭 → 초반 박수/NG와 빠진 배경 설명이 있는 12초 원본 영상(`sample-12s.webm`) 업로드.
- **화면 변화:**
  - 상태 배지가 `멀티모달 분석 중 (/api/plan)`으로 전환.
  - 우측 **Argon Director** 패널에:
    1) **불확실 사실(`uncertainFacts`)** 호박색 경고 박스 표시 (수치 날조 방지).
    2) **자동 컷 편집(`cuts`)**: 박수·NG(`confidence 96%`)는 자동 컷 ON, 애매한 침묵(`confidence 58% < 0.7`)은 자동 삭제하지 않고 **`제안 (사용자 확인)`** 토글로 표시.
    3) **빠진 설명 발견(`gaps`) — WOW 배너**: *"★ 찍지 않은 설명 장면이 생겼다"* 와 함께 보완할 모션 장면 2개와 엔딩 카드가 타임라인에 삽입됨.
- **대사:**
  > "원본 영상을 올리면 Argon이 영상을 보고 들으며 대사를 전사하고 NG 구간을 잡아냅니다. 확신도가 0.7 미만인 구간은 멋대로 자르지 않고 크리에이터에게 제안으로만 보여줍니다. 무엇보다 놀라운 점은, 발화자가 말로만 툭 던지고 넘어간 **빠진 설명 구간(Gap)**을 스스로 찾아내어, 원래 찍지 않았던 모션그래픽 설명 장면을 타임라인 사이에 설계한다는 것입니다."

### 3. [0:50 ~ 1:35] 모션 코드 생성 · Worker 샌드박스 · 시각 검증 루프 (`/api/scene-code`, `/api/verify`) (45초)
- **화면:** 중앙 16:9 Canvas 플레이어에서 **흰 여백(`#F8F9FA`) + 먹색 타이포(`#111111`) + 라임 포인트(`#C6FF00`)** 톤의 키네틱 비교 카드와 3단계 파이프라인 다이어그램이 실시간 60fps로 재생됨.
- **행동:**
  - 우측 Director 패널의 장면 카드 2번(`scene-2-motion-compare`)에서 **3대 배지**(`source: argon-code`, `attempts: 1`, `✓ 시각 검증 통과`)를 가리킨 뒤 **`[코드 보기]`** 클릭.
  - Argon이 직접 작성한 `function draw(ctx, t, w, h, scene)` 순수 Canvas 2D 코드와 하단 **실시간 모델 호출 로그**(`/api/plan`, `/api/scene-code`, `/api/verify` 소요 시간 및 상태)를 보여줌.
- **대사:**
  > "이 모션그래픽은 미리 만든 비디오 클립이 아닙니다. Argon이 각 장면의 대본에 맞춰 HTML5 Canvas 2D `draw(ctx, t, w, h, scene)` 자바스크립트 코드를 즉석에서 작성했습니다. 생성된 코드는 네트워크가 차단된 **Web Worker + OffscreenCanvas 샌드박스**에서 2초 타임아웃과 빈 화면 픽셀 검사를 거치고, 실패하면 `/api/fix-code`로 스스로 고칩니다. 마지막으로 렌더링된 키프레임 이미지를 다시 Argon 멀티모달(`/api/verify`)에 보여줘 글자 가독성과 대본 일치 여부까지 검증을 마쳤습니다."

### 4. [1:35 ~ 2:15] 자연어 한 줄 장면 수정 (`/api/revise`) (40초)
- **행동:** 장면 카드 하단 수정 입력창에 **`"make this simpler"`** (또는 빠른 칩 클릭) 입력 후 **`[이 장면 수정 (/api/revise)]`** 클릭.
- **화면 변화:**
  - `/api/revise`가 호출되어 해당 장면의 캡션·시각 아이디어와 Canvas `draw()` 코드가 즉시 업데이트되고, `attempts` 배지가 올라가며 플레이어 화면이 실시간으로 더 간결하고 임팩트 있게 바뀜.
- **대사:**
  > "마음에 안 드는 장면이 있다면 편집 프로그램을 열 필요 없이 자연어로 한 줄만 지시하세요. `/api/revise`를 통해 Argon이 해당 장면의 기획과 Canvas 렌더링 코드를 즉시 다시 짜고 샌드박스 검증까지 마쳐 화면에 반영합니다."

---

### 5. [2:15 ~ 3:00] 완성 영상 내보내기 & 마무리 (`MediaRecorder` + WebAudio) (45초)
- **행동:** 상단 우측 **`[완성 영상 다운로드 (MP4/WebM)]`** 버튼 클릭.
- **화면 변화:**
  - 진행률(0% → 100%)이 올라가며 원본 `keep` 구간 + Argon이 짠 모션그래픽 장면 + 하단 자막 + 오디오 트랙이 하나로 합성된 영상 파일이 생성·다운로드되고, 상단 인라인 플레이어에서 즉시 재생됨.
- **대사:**
  > "마지막으로 다운로드 버튼을 누르면 브라우저의 Canvas 합성기와 MediaRecorder가 컷 편집된 원본 구간, Argon이 코딩한 모션그래픽 장면, 자막, 오디오를 하나의 영상 파일로 내보냅니다.
  > 기획(`plan`)부터 모션 코딩(`scene-code`), 샌드박스 자가 수정(`fix-code`), 멀티모달 시각 검증(`verify`), 자연어 수정(`revise`)까지—크리에이터를 위한 완벽한 에이전틱 루프, **YouTube AI Studio**였습니다. 감사합니다."
